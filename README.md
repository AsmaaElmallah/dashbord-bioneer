# لوحة تحكم بيانور (UI فقط)

مشروع React + Vite منفصل عن تطبيق Flutter `bayanour/`.

## التشغيل

```bash
cd bayanour_admin_ui
npm install
npm run dev
```

افتح: **http://localhost:5173**

## البناء

```bash
npm run build
npm run preview
```

## حدود

- لا Backend / API / DB
- كل البيانات mock في `src/data/mockData.js`
- أزرار الحفظ تعرض snackbar «UI فقط»
